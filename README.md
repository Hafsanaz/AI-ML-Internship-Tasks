# AI-ML-Internship-Tasks

Machine learning and AI tasks completed as part of the **Arch Technologies AI/ML Internship**. Each task tackles a different classic ML problem, covering data preprocessing, model building, and evaluation.

## 📂 Tasks

| Task | Description |
|------|-------------|
| **Iris Flower Classification** | Classifies iris flowers into species (Setosa, Versicolor, Virginica) based on petal and sepal measurements — a foundational multi-class classification problem. |
| **Housing Price Prediction** | Predicts housing prices using regression techniques based on features such as location, size, and number of rooms. |
| **Email Spam Classification** | Classifies emails as spam or not spam using text preprocessing and NLP-based classification techniques. |
| **Mnist Digit Recognition** | Recognizes handwritten digits (0–9) from the MNIST dataset using a machine learning / deep learning model. |

## 🛠️ Tech Stack

- **Language:** Python
- **Libraries:** NumPy, Pandas, Scikit-learn, Matplotlib/Seaborn, (TensorFlow/Keras or PyTorch for MNIST)
- **Environment:** Jupyter Notebook

## 📁 Repository Structure

Each task is provided as a compressed `.zip` file containing the notebook/script, dataset (or dataset link), and any supporting files:

```
AI-ML-Internship-Tasks/
├── Iris Flower Classification.zip
├── Housing Price Prediction.zip
├── Email Spam Classification.zip
├── Mnist Digit Recognition.zip
└── README.md
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Hafsanaz/AI-ML-Internship-Tasks.git
   cd AI-ML-Internship-Tasks
   ```
2. Extract the zip file for the task you want to explore:
   ```bash
   unzip "Iris Flower Classification.zip"
   ```
3. Install the required dependencies (typically):
   ```bash
   pip install numpy pandas scikit-learn matplotlib seaborn jupyter
   ```
4. Launch Jupyter Notebook and run the corresponding notebook:
   ```bash
   jupyter notebook
   ```
